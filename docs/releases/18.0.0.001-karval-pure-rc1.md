## What "pure" means in this release

This release is the PG18 base/database stack release before project DDL installation.

Included:

- PostgreSQL 18 image/fork based on the open-source `supabase/postgres` image recipe.
- Curated compiled extension surface validated for this fork.
- Accepted preload configuration:

```text
pg_stat_statements, pgaudit, pg_cron, pg_net, pg_tle, safeupdate
```

- Local digest-pinned PostgREST/JWT/RLS proof stack.
- Local realtime v2 proof stack based on:
  - `private.event_outbox` as durable event source;
  - `LISTEN/NOTIFY` as wake-up signal;
  - WebSocket bridge;
  - replay/cursor;
  - scopes/topics;
  - DB-owned subscription checks;
  - ACK storage.
- HTML proof page for human inspection.
- `llms.txt` and `llms-full.txt` for agent/human context.
- Versioned DDL directory conventions.

Not included:

- No Prop4You project DDL installed.
- No project/customer schema baked into the image.
- No Strapi database or Strapi integration.
- No production/VPS deployment claim.
- No Redis/NATS/Kafka runtime requirement.
- No full Supabase hosted platform stack claim.

## Why this exists

Supabase does not currently provide a PostgreSQL 18 image/fork as the canonical upstream release line. This repository is the Karval-controlled PG18 original/fork line for the database image and local database-centric stack proof.

The goal is to keep the base database runtime clean and reusable, then install project DDL packages later through ordered `.sql` packages.

## DDL boundary

The base image/stack and project DDLs are intentionally separate.

DDL package root:

```text
database/ddl/
```

Initial project case:

```text
database/ddl/projects/prop4you/
```

Project DDLs must be installed later into a running database and tracked as ordered `.sql` files. They are not part of this pure release.
